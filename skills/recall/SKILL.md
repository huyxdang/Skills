# Recall

Pin the topic, workspace, and date range from the request. For unspecified recent work use seven days and state that assumption. Do not narrow an explicit all-history request silently.

Use supported chat list/search/read tools. Read only relevant chats; do not scan private filesystem transcript stores. A supplied state capsule may make history mining unnecessary. Use `../swarm/SKILL.md` only for substantial independent slices.

For a named subsystem, consult relevant shared records with `../why/SKILL.md`. Verify surfaced PRs, branches, issues, and artifacts against live state. A transcript claim is not evidence that a change shipped. When sources are unavailable, state what the brief cannot establish.

Return a compact current-state capsule, one status per workstream, recurring problems or failed approaches, and the next useful action. Use actual evidence-based statuses, including unknown when needed. This is context reconstruction; do not resume edits unless requested.

## Codex execution
