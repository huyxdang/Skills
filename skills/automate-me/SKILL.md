# Automate Me

Inspect an existing matching mode skill and preserve its established scope and invocation policy. Use the current conversation first. When history is needed, discover Codex chat search/read tools and restrict searches to the requested project, topic, and period. Never scan unrelated private transcript directories.

Separate explicit preferences from inferred recurring patterns. A single exception is not a universal rule. Ask only for missing preferences that affect the result; avoid a mandatory interview when the request is already clear.

Use the available skill-creator guidance to author or update the mode. Capture specific non-default conventions, reference available skills rather than copying them, and keep authorization boundaries unchanged. Choose a discoverable personal or project location according to the user's request and environment. Do not edit a plugin cache.

Run metadata and link validation, inspect the result, and present what changed and the supporting evidence. A request to draft ends with a draft; a request to update authorizes in-scope edits. Commit, push, publish, or file tickets only when included in the request.

## Codex execution

Resolve bundled paths from this skill directory. Read a named sibling skill before using its workflow; if it is not installed, report that dependency and use only capabilities actually available.
