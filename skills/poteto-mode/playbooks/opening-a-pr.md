# Opening a pull request

1. Confirm the user requested a pull request or clearly requested delivery by PR.
2. Inspect status and diff. Preserve unrelated and user-owned changes.
3. Run the repository's relevant tests and record what was not run.
4. Create focused commits without generated noise or secrets.
5. Push through the repository's established workflow.
6. Open the pull request with outcome, implementation, proof, and remaining risk.
7. Verify the remote head revision matches the local revision.
8. Return the real pull request URL.

Do not force-push, rewrite shared history, or merge without explicit authority.
