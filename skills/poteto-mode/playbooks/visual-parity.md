# Visual parity

1. Fix the reference viewport, state, content, fonts, and assets.
2. Capture reference and target images at identical dimensions.
3. Compare layout geometry before color and decoration.
4. Fix the largest shared cause rather than individual pixels.
5. Repeat captures after each coherent change.
6. Verify keyboard, responsive, and interaction behavior when they are in scope.
7. Inspect the final rendered surface and console.

Report any remaining mismatch with an image or precise region, not a vague
percentage.
