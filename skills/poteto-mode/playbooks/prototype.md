# Prototype

1. Write the decision the prototype must settle.
2. Define one observable discriminator between the credible options.
3. Build the smallest disposable probe that exposes that discriminator.
4. Run it against representative input.
5. Record the result and choose or reject an option.
6. Remove the probe unless the user asked to keep it or it became a useful test.

Do not let prototype structure become production architecture by accident.
