# Hillclimb

1. Define one metric, workload, baseline, target, and stop condition.
2. Keep a decision log with hypothesis, evidence, result, and disposition.
3. Change one material variable per iteration.
4. Measure with the same harness.
5. Accept only a repeatable win that preserves correctness.
6. Revert or discard losses before the next iteration.
7. Checkpoint each accepted win as an independently verifiable unit.
8. Stop at the target, exhausted budget, or evidence that the objective is wrong.
