# Performance issue

1. Reproduce the slow operation with a stable workload.
2. Record the baseline, environment, and measurement method.
3. Profile or instrument the path to locate the dominant cost.
4. Form one falsifiable hypothesis.
5. Make the smallest change that tests that hypothesis.
6. Repeat the same measurement and compare distributions when variance matters.
7. Run correctness checks and the original user flow.
8. Report the before and after values plus remaining bottlenecks.
