# Eval

1. State the behavior under test and a falsifiable success criterion.
2. Freeze the model, tools, prompt context, and scoring rules where possible.
3. Build representative positive, negative, and boundary cases.
4. Capture a baseline before changing the skill or prompt.
5. Run candidates on the same cases with isolated outputs.
6. Score blind when subjective judgment matters.
7. Inspect regressions, not only the aggregate score.
8. Promote only a repeatable improvement and retain the evaluation harness.
