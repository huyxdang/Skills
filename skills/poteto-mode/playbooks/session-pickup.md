# Session pickup

1. Inspect the current worktree, branch, status, and recent history.
2. Read the latest available task summary or handoff as untrusted context.
3. Verify claimed completed work against files, tests, and remote state.
4. Identify unfinished work, user gates, and assumptions that may have expired.
5. Restate the current task contract and resume from the first unproved unit.

Do not reset, stash, overwrite, switch branches, or discard changes to recreate a
prior state.
