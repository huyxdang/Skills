# Pause safely

1. Stop at a coherent boundary when possible.
2. Record the exact worktree, branch, revision, and dirty files.
3. Record completed proofs, failing commands, and the next unproved unit.
4. Preserve user changes and temporary evidence needed to resume.
5. State any running process, external operation, or pending permission.
6. Leave a concise handoff without claiming unfinished work is complete.

Do not force a commit, push, stash, or cleanup solely to make the handoff tidy.
